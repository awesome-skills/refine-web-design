# Refine Web Design

Review and improve website design with concrete evidence and a bounded iteration budget.

## Install

```bash
npx skills@latest add awesome-skills/refine-web-design -g -y
```

If you use the unified Agent Skills Manager, import the `skills/refine-web-design` directory through its local installation workflow.

## Use

```text
Use $refine-web-design to review this page and improve its design within three rounds.
```

You can also explicitly invoke `@refine-web-design` in clients that support that syntax. Invocation syntax depends on your agent. Chinese trigger phrases are retained in the skill.

## Behavior

Checks composition, typography, color, visual identity, responsiveness, usability and accessibility, interaction, and performance. Defaults to at most three rounds, with actual desktop and mobile previews. Reports unverified areas when a browser is unavailable. Review-only requests do not authorize edits or publishing. Award-caliber design is an aspiration, not an official score or an award guarantee.

Read the complete [skill instructions](skills/refine-web-design/SKILL.md).
